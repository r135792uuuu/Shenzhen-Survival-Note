# 🌴 深圳生存指南 · Shenzhen Survival Note

> 写给刚来深圳实习 / 工作的朋友们：**用低成本，把日子过得舒服。**
> 这是我在深圳实习期间一点点蹲出来的省钱笔记——从买机票、领补贴，到蹲超市折扣、搭配营养，全在这一个仓库里。

---

## 📖 关于本指南

- **写给谁**：刚到深圳实习、工作的朋友，尤其是第一次自己管一日三餐的人。
- **想解决什么**：不牺牲健康和生活体验的前提下，尽量压低每月固定开销。
- **覆盖范围**：深圳宝体、坪洲、前进路一带的商超（沃尔玛 / 盒马 / 小象 / 永辉 / 多多买菜 / 朴朴），以及营养搭配、备餐方案、机票补贴、外卖团购捡漏技巧。
- **价格说明**：所有价格均为个人实购记录，会随时间波动，**请以现场实际为准**；能砍价的菜市场永远更便宜。

## 🧭 怎么用这份指南

1. 不知道该蹲哪家店 → 先看文末「总结」；
2. 想吃得健康又便宜 → 看「营养搭配」和「备餐方案」；
3. 记住几个捡漏时间点：**盒马 20:00 后**、**永辉 20:30 后**、**棒约翰 20:30 后**、**惜时魔法袋 20:30 / 22:30 后**。

## ⚠️ 三条原则

1. **打折才买** —— 大部分原价商品都有折扣平替，等它打折。
2. **注意保质期** —— 临期折扣品多数当天或次日到期，买了就尽快吃。
3. **营养别省** —— 省钱省在渠道上，不省在营养上：蛋白质、膳食纤维、维生素该补就补。

## 一、行前与外卖

### ✈️ 买机票
- 各航空公司的次卡，如 **海南航空 666 / 2666** 的次卡套餐。

### 🏢 实习生补贴
- 如果是**实习生**，关注深圳**各区**的实习生补贴。
- 很多**五折券**，但需要**一个月内用完**。
- 参考：`100-50`、`50-25`、`20-10`。

### 🥬 多多买菜
- 买**鸡蛋、蔬菜、生活用品**还行。
- **买肉就算了**（质量一般）。

## 二、营养搭配

> 下面价格尽量往高了写，**菜市场砍价**或**路边老爷爷卖的**会更便宜。

### 🐟 金枪鱼罐头（补充 Omega-3 / 硒 / B12）
- PDD 一罐 **3 块左右**。
- 每次吃 **1/3 勺**，**一周 2-3 次**即可。
- 三文鱼太贵，活鱼懒得做 → 直接用金枪鱼替代。

### 💊 维生素类
- **维生素 B 族 + 叶酸**：直接吃复合维生素 B 片。
- **钙 + 维生素 D**：靠牛奶，或补剂。

### 🥬 绿叶菜对比

| 蔬菜 | 价格 | 优点 | 备注 |
|------|------|------|------|
| **菠菜** | 6 元/斤 | 补叶酸、钾、镁、钙 | 用热水焯水去掉草酸 |
| **苋菜**（血汗菜） | 10 元/斤 | 叶酸、钙、叶黄素都比菠菜高 | — |
| **上海青** | 便宜 | 钙高且便宜 | — |
| **西洋菜** | — | 蔬菜之王 | — |

> ⚠️ **注意**：所有绿叶菜的钙、铁吸收率都很低，不够要**单独补充**。

### 🥦 西兰花（重点推荐）
- 小象 **200g / 2.06 元**。
- 优点：维 C 高、高蛋白、维 K、钾、**萝卜硫素**高。
- 做法：**切开**，**上锅蒸 3-5 分钟**（水煮会流失一点营养）。

### 🍅 其他蔬菜
- 白菜、包菜、西红柿等按需搭配。

## 三、备餐方案

> 经常晚上做当晚 + 明天中午两顿，前提是**回去不晚 + 有心力**去做。

### 经典搭配
1. **一块鸡胸肉**撕条，吃两顿
2. **半盒西兰花**
3. **一个番茄**
4. 主食随意搭配一点
5. **两袋鹰嘴豆**
6. 一份水煮蔬菜，分两份
7. 倒酱料 + 橄榄油

### 轮换与补充
- 偶尔换成**豆腐**和**鸡蛋**。
- 每周两三次**金枪鱼罐头**。
- **维生素 B 每天吃**。
- 没摄入铁和锌就吃一颗**铁锌片**。
- 偶尔加点**碘盐**。

## 四、商超折扣攻略

### 🐘 小象超市（重点渠道）

**常驻折扣**
- 奥尔良鸡排一盒两块，经常五折只要 **7 块**。
- 藤椒鸡腿经常折扣。
- 偶尔蹲到 **1.5 的牛奶**、**七毛一瓶的益生菌汽水**。
- **酸奶**经常买一送一 / 折扣。
- 家庭用水：桶装水 **2 瓶共 10L / 12 元**（有超重配送费，多买打折平摊）。
- 鸡蛋：**15 个装 12.9 元**。

**膳食纤维**
- 直接买**鹰嘴豆罐头**，3-5 块一罐，每天挖几勺就补上了。

**肉类（蛋白质）**
- 优先买上面折扣的鸡排鸡腿肉。
- 没有就买**冷冻鸡胸**，**1kg / 16 块**，直接水煮 **15 分钟**。
- 没味道就买酱料：推荐 **味好美藤椒风味沙拉酱**（PDD 买，味道 60% 接近赛百味双椒酱）。

**主食**
- 优先**土豆**（吃腻了换玉米粉，一包几块钱）。
- 也推荐 **世壮燕麦**：没加糖，β葡聚糖和膳食纤维好，也能当主食。
- 也可以买超市方便面饼（一饼 1 块）应急。
- PDD：**特级初榨橄榄油试吃装 9.9**，补充优质油脂。
- 逛番茄/抖音刷到意大利面可以捡漏（有牌子一盒 2 块，很好吃）。

**⚠️ 小象省钱技巧（重点）**
- 小象超市**直接去美团闪购界面**用，还有吃喝玩乐对应膨胀券。
- 闪购里可以**领红包自动凑单**，比 App / 小象页面便宜多了。
- 商品在左侧找，也有清仓栏，推荐算法不好，要慢慢找。

### 🏬 坪洲大仟里·永辉超市

- 冰库区散落一些打折的，要**一个柜子一个柜子看**。
- 捡到过的：黄米开心果汤圆 **4.9**、撒尿牛丸 **5**、涮羊肉一盒 **21**。
- **收银处折扣区**商品会更新，去发现。
- **八点半后**可捡漏：
  - 水果区：苹果、树莓、荔枝、芭乐（比沃尔玛多、更便宜）。
  - 蔬菜折扣区捡漏多，但价格普遍还是比沃尔玛贵。
- 土豆泥 8 块，熟食/面包/肉类基本 7-8 折（偏贵）。
- 肉类唯一优势：可现场帮你制作。

## 七、外卖与团购

### 朴朴超市
- 抖音直播间有券，最大见过 **99-45**，可买食物 + 日用。

### 棒约翰
- 宝体沃尔玛旁边最近的那家，**八点半后披萨 19.9** 捡漏。

### 惜时魔法袋
- 随时关注，需要**晚上 8:30 / 10:30** 之后去领取。

### 赛百味
- 蹲直播间和抖音优惠券。
- 最便宜买过 **11 块一个**，平常 **不高于 14**，高了没必要买。

### 牛肉（补铁）
- 缺铁就吃牛肉，买 **钱大妈抖音直播间**的优惠，各种牛肉从多到少。

### 抖音团购饺子
- 袁小饺等：生饺子 / 云吞基本 **10-15 块**。
- 虾的 10 个，普通的 30 个。

### 美团闪购（通用技巧）
- 有闲时间可领闪购红包，去美团闪购买小象清仓折扣。
- 和 App 一样，只是没有推荐算法，要一页一页滑。

## 总结

- **沃尔玛**打折品比较固定，肉/菜折扣区值得固定蹲。
- **小象超市**走美团闪购更划算，清仓 + 红包凑单。
- **盒马**晚上 8 点后线下 + 抖音直播间 7 折券最划算。
- **永辉**去大仟里店，八点半后水果区捡漏最香。
- 日常营养公式：**燕麦 / 土豆 + 便宜绿叶菜 + 折扣鸡腿鸡排 + 金枪鱼罐头 + 复合维 B**。
- 机票 / 补贴 / 团购：凑各种次卡、五折券、直播间优惠券，**价格高于阈值就不要买**。
