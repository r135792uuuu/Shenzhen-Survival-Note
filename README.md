# 🌴 深圳生存指南 · Shenzhen Survival Note

> 写给刚来深圳实习 / 工作的朋友们：**用低成本，把日子过得舒服。**
> 这是我在深圳实习期间一点点蹲出来的省钱笔记——从买机票、领补贴、找房子，到蹲超市折扣、搭配营养，全在这一个仓库里。

---

## 📖 关于本指南

- **写给谁**：刚到深圳实习、工作的朋友，尤其是第一次自己管一日三餐的人。
- **想解决什么**：不牺牲健康和生活体验的前提下，尽量压低每月固定开销。
- **覆盖范围**：深圳宝安中心一带的商超（沃尔玛 / 盒马 / 小象 / 永辉 / 多多买菜 / 朴朴），以及营养搭配、备餐方案、机票补贴、租房避雷、外卖团购捡漏技巧。
- **价格说明**：所有价格均为个人实购记录，会随时间波动，**请以现场实际为准**；能砍价的菜市场永远更便宜。

## 🧭 怎么用这份指南

1. 不知道该蹲哪家店 → 先看文末「总结」；
2. 想吃得健康又便宜 → 看「营养搭配」和「备餐方案」；
3. 记住几个捡漏时间点：**沃尔玛/盒马 20:00 后**、**永辉 20:30 后**、**棒约翰 20:30 后**、**惜时魔法袋 20:30 / 22:30 后**。

## ⚠️ 三条原则

1. **打折才买** —— 大部分原价商品都有折扣平替，等它打折。等不到就上 pdd 看替代。
2. **注意保质期** —— 临期折扣品多数当天或次日到期，买了就尽快吃。
3. **营养别省** —— 省钱省在渠道上，不省在营养上：蛋白质、膳食纤维、维生素该补就补。

## 一、行前准备

### ✈️ 买机票
- **海南航空 666 / 2666 次卡**：买下权益后，有你想飞的航线只需 **199 + 基建燃油**，但注意**只有红眼航班**；666 不含暑运、春运和五一十一，2666 不含暑运和春运。
- **春秋 / 川航 / 东航等各家次卡**：每家航司航线城市不同，需要蹲守直播间；买一两次就知道自己常飞的是哪几家。**南航有学生优惠**，暑期可以买，避开暑运高价。
- ⚠️ 不推荐航空公司以外平台的机票优惠（刷几个机票直播间就知道我在说什么了），不如直接在平台上买。

### 🏢 实习生补贴
- 如果是**实习生**，关注深圳**各区**的实习生补贴。
- 满足条件的话，上**小红书**搜"深圳市实习补贴"，看看自己有没有资格申请。
- 很多**五折券**，但需要**一个月内用完**。
- 参考：`100-50`、`50-25`、`20-10`。

### 🏠 租房
- 实习时间不长的，直接上**小红书看转租**，找地段和价格都合适的，比直接找中介好。
- **分辨真假中介 / 广告**：
  - 小红书上的宣传和线下带看是**两拨人**——你看到很好的房子，线下带看的人会说那是骗人用的；线下的人找到你之后，线上发帖的人直接不回你。
  - 看着就**特别漂亮**的大概率是假的；简介或加上微信后显示**全深圳各区都有房源**的必然不是真中介（真中介的朋友圈基本都在一两个区内带人看）。
- **带你看新装修房子的一概直接拉黑**，装修再漂亮也是让你去吸甲醛。有账号的记得去帖子下适当避雷，帮大家分辨黑中介和虚假宣传。
- **小红书上有「扫楼」的**：支付一些灵石，就能让人帮你避雷那些货不对板的房子；拿到初筛结果后自己实地去看、直接和房东谈价格就行，一般比中介便宜很多。
- 别图便宜住脏乱差：阴暗潮湿、很脏、楼下是大排档的地方，蟑螂虫子到处爬，容易生病。
- 有朋友推荐的最好——实地住过才知道环境如何、生活是否舒服、房东会不会管事。

## 二、营养搭配

> 下面价格尽量往高了写，**菜市场砍价**或**路边老爷爷卖的**会更便宜。

### 🐟 金枪鱼罐头（补充 Omega-3 / 硒 / B12）
- PDD 一罐 **6 块左右**（这个价位的"金枪鱼"很多其实是鲣鱼，营养类似，无所谓）。
- 每次吃 **1/2 罐**，**一周 2-3 次**即可。
- 三文鱼太贵、活鱼懒得做 → 直接用金枪鱼罐头替代。

### 💊 维生素类
- **维生素 B 族 + 叶酸**：
  - **B1、B6**：多吃粗粮——燕麦、糙米、土豆这些。
  - **B2、B12**：多吃鱼虾蛋奶——鸡蛋、鸡胸肉、金枪鱼，加上深绿蔬菜。
  - 嫌麻烦就每天一片**复合维生素 B 片**。
- **钙 + 维生素 D**：牛奶、豆腐、红苋菜、金枪鱼罐头，或补剂。

### 🧪 微量元素：维 K / 钾 / 镁 / 铁 / 锌

| 元素 | 作用（缺了会怎样） | 平价来源 |
|------|------|------|
| **维生素 K** | 凝血 + 引导钙沉积进骨头（牙龈出血、淤青难消） | 深绿蔬菜都高：西兰花、菠菜、苋菜，日常吃就够 |
| **钾** | 乏力、抽筋（深圳夏天出汗多流失快） | **土豆**最便宜大碗，香蕉、西红柿、焯过水的菠菜 |
| **镁** | 抽筋、睡眠差 | 燕麦 / 粗粮、鹰嘴豆、深绿蔬菜、坚果 |
| **铁** | 脸色白、头晕、指甲脆 | 吸收率：红肉（牛肉）> 蛋 / 鸡肉 > 植物铁；菠菜的铁吸收率低，和西红柿（维 C）一起吃能翻倍 |
| **锌** | 伤口好得慢、味觉变差、皮肤变差 | 鸡腿肉、鸡蛋、鹰嘴豆、燕麦 |

> 铁、锌吃不够就每天一片**铁锌片**；缺铁明显直接上**钱大妈直播间牛肉**。
>
> ⚠️ **补剂提醒**：**不要多吃**——很多添加剂会导致肠胃和肝脏难受。结合你最近三五天的营养摄入，隔几天吃对应的那种就行。个人经历：善存多维复合补剂我吃了没事，我父母一吃就拉肚子——因人而异，需要自己小量尝试，我更推荐**食补**。

### 其他
- **膳食纤维**：直接买鹰嘴豆罐头或杂豆罐头，一罐 3-6 块，500g 够吃一周。
- **优质脂肪**：PDD 买特级初榨橄榄油（试用装那种），够吃很久。

### 🥬 常见绿叶菜对比

| 蔬菜 | 价格 | 优点 | 备注 |
|------|------|------|------|
| **菠菜** | 6 元/斤 | 补叶酸、钾、镁、钙 | 用热水焯水去掉草酸 |
| **苋菜**（血汗菜） | 10 元/斤 | 叶酸、钙、叶黄素都比菠菜高 | — |
| **上海青** | 便宜 | 钙高且便宜 | — |
| **西洋菜** | — | 蔬菜之王 | — |

> ⚠️ **注意**：所有绿叶菜的钙、铁吸收率都很低，不够要**单独补充**。

### 🥦 西兰花（重点推荐）
- 小象 **200g / 2.06 元**。
- 优点：维 C 高、高蛋白、维 K、钾、**萝卜硫素**高。
- 做法：**切开**，**上锅蒸 3-5 分钟**（水煮会流失一点营养）。

### 🍅 其他蔬菜
- 白菜、包菜、西红柿等按需搭配。

## 三、备餐方案

> 经常晚上做当晚 + 明天中午两顿，前提是**回去不晚 + 有心力**去做。

### 经典搭配
1. **一块鸡胸肉**撕条，吃两顿
2. **半盒西兰花**
3. **一个番茄**
4. 主食随意搭配一点
5. **两袋鹰嘴豆**
6. 一份水煮蔬菜，分两份
7. 倒酱料 + 橄榄油

### 轮换与补充
- 偶尔换成**豆腐**和**鸡蛋**。
- 每周两三次**金枪鱼罐头**。
- **维生素 B 每天吃**。
- 没摄入铁和锌就吃一颗**铁锌片**。
- 偶尔加点**碘盐**。

### 🌅 早餐方案
- 楼下包子铺的账：一个鸡蛋 **1.5**，一个肉包 **1.5 起步**，一个早上想吃好接近 **5 块**。
- **推荐自己买冷冻包子**或爱吃的早餐（各家超市都有，鸡蛋也超市买更便宜），早上有时间花 **10 分钟蒸熟**，成本能砍一半以上。
- **不想动手的**：买即食燕麦或即食小麦胚芽，都在 **PDD** 买。
- **选哪款直接问豆包**：让它对比营养含量和性价比；豆包聊着聊着常会推送**带优惠券的同款**——营养成分差距不大、价格更便宜的话，就支持一下豆姐（例如我拿到 **8.9 元 / 500g 的纯小麦胚芽早餐**）。

## 四、商超折扣攻略

### 🐘 小象超市（重点渠道）

**常驻折扣**
- 奥尔良鸡排一盒两块鸡排，经常五折只要 **7 块**。
- 藤椒鸡腿经常折扣，最低买过 **10 块**。
- 偶尔蹲到 **1.5 的牛奶**、**七毛一瓶的益生菌汽水**。
- **酸奶**经常买一送一 / 折扣。
- 家庭用水：桶装水 **2 瓶共 10L / 12 元**（有超重配送费，多买打折平摊）。
- 鸡蛋：**15 个装 12.9 元**。

**肉类（蛋白质）**
- 优先买上面折扣的鸡排鸡腿肉。
- 没有就买**冷冻鸡胸**，**1kg / 16 块**，直接水煮 **15 分钟**。
- 没味道就买酱料：推荐 **味好美藤椒风味沙拉酱**（PDD 买，味道 60% 接近赛百味双椒酱），热量有点高，可以配些低热量的**油醋汁**。

**主食**
- 优先**土豆**，吃腻了换**玉米粉**（一包几块钱）。
- 推荐 **世壮燕麦**：没加糖，β葡聚糖和膳食纤维好，也能当主食。
- 米面主食各家价差大，不赘述；实测**七色糙米**买一送一，一袋 9.9 元 1kg（到手 2kg，约 5 元/kg）。
- 也可以买超市方便面饼（一饼 1 块）应急。
- 逛番茄/抖音刷到意大利面可以捡漏（有牌子一盒 2 块，很好吃）。

**⚠️ 小象省钱技巧（重点）**
- 小象超市**直接去美团闪购界面**用，还有吃喝玩乐对应膨胀券。
- 闪购里可以**领红包自动凑单**，比 App / 小象页面便宜多了。
- 商品在左侧找，也有清仓栏，推荐算法不好，要慢慢找。
- 但是我多次实测下来有些折扣商品只要小象APP才有，美团闪购的没有部分清仓价和买一送一。

**📌 社区补充（issue · 石鼓附近盒马实测）**
- 生鲜区**定期打折的菜和肉**基本每次去都能买到：**鸡腿肉丁、黑猪肉丝、各种净菜**，一般**七折**。盒马的菜是包装好的、不搞当天废弃，所以日常去就能碰上。

- **盒马会员值得开**：打折商品之外，每天还能领一个免费菜——可能是四个鸡蛋、一把蔬菜，甚至洗面奶。

## 五、水果篇

### 🏪 周边水果店（优先推荐）
- 先了解住的周边有哪些水果店，**直接买比超市便宜很多**。
- 超市的水果可以认为是**精品水果**，水果店卖的就是**正常的水果**——日常吃去水果店就够，想吃好的再去超市蹲折扣。

### 沃尔玛（只看打折，不是全有）
- 菠萝 / 哈密瓜 / 木瓜，两盒果切 **17**。
- 树莓一盒 **15**。
- 蓝莓 125g **9**。

### 小象特惠页面
- 蓝莓两盒 **16.89**（但没沃尔玛的好吃）。
- 直接搜"买一送一"。
- 200g 小炒牛肉片打折 **22**。
- 300ml HPP 饮料（番茄/黄瓜沙拉等）打折 7-8 块。

### 🫐 蓝莓选购
- 季节款在楼下水果店或开三轮车的有。
- **只推荐打折时买**；深圳最便宜买过 **10 块两盒 250g**。
- 各大商超晚上有高级蓝莓折扣，口感确实不一样。

## 六、零食饮料篇

### 🏷️ 好特卖（HotMaxx）
- 买零食、酒水饮料推荐**好特卖**，附近有店可以去逛；有的店还有各种生活日用品，价格其实还行。

### 沃尔玛打折
- 姜黄饮料 **6.8**。
- 小瓶果茶：二次折扣 **4.89**、一次折扣 **6.89**。
- 瓶装酸奶看品牌；牛奶打折便宜 2-4 块。
- 透明小塑料瓶气泡水果汁 **4.9**。
- 勺吃酸奶打折后均价 **3-4 元/盒**。
- HPP 西瓜汁少有折扣，折后 **9.9**。
- 四瓶小装牛乳茶 / 芋泥奶养生饮料：**3.5 一瓶**（四瓶一组）。
- 小盒锡纸蛋糕打折 **5 块**（好吃，有棕蓝绿三种味道）。

### 小象
- 水两大桶 5L 的 **8.9**，加运费 **11.9**。

## 七、外卖与团购

### 朴朴超市
- 抖音直播间有券，最大见过 **99-45**，可买食物 + 日用。
- 有时开抖音直播间，基本都是 **99-45**，商品一般是**水、牛奶、速冻食品**——刚好刷到、且你要的在凑单区间里的话还是很划算的。

### 棒约翰
- **八点半后披萨 19.9** 捡漏。

### 惜时魔法袋
- 随时关注，需要**晚上 8:30 / 10:30** 之后去领取。

### 赛百味
- 蹲直播间和抖音优惠券。
- 最便宜买过 **12 块一个**，平常 **不高于 15**，高了没必要买，自制更便宜。

### 牛肉（补铁）
- 缺铁就吃牛肉，买 **钱大妈抖音直播间**或者商超的晚间折扣的优惠，各种牛肉从多到少。

### 抖音团购饺子
- 袁小饺、云饺等：生饺子 / 云吞基本 **10-15 块**。
- 虾的 10 个，普通的 30 个。

### 美团闪购（通用技巧）
- 有闲时间可领闪购红包，去美团闪购买小象清仓折扣。
- 和 App 一样，只是没有推荐算法，要一页一页滑。

5. 米面主食各家价差大不赘述，看到买一送一再下手。

## 总结

- **沃尔玛**打折品比较固定，肉/菜折扣区值得固定蹲。
- **小象超市**走美团闪购更划算，清仓 + 红包凑单。
- **盒马**晚上 8 点后线下 + 抖音直播间 7 折券最划算。
- **永辉**去大仟里店，八点半后水果区捡漏最香。
- **多多买菜**整体最便宜但次日达：鸡蛋蔬菜日用闭眼买，肉别买。
- 日常营养公式：**燕麦 / 土豆 + 便宜绿叶菜 + 折扣鸡腿鸡排 + 金枪鱼罐头 + 复合维 B**。
- 机票 / 补贴 / 团购：凑各种次卡、五折券、直播间优惠券，**价格高于阈值就不要买**。
